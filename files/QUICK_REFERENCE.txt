  BATCH VERIFICATION:
  ───────────────────
    import asyncio
    from phone_verifier import PhoneVerifier
    
    async def batch():
        v = PhoneVerifier()
        numbers = ['+2348012345678', '+1202-555-0173']
        for num in numbers:
            r = await v.verify_phone_complete(num)
            await asyncio.sleep(0.3)
    
    asyncio.run(batch())

⚠️ TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────

  Problem: "ModuleNotFoundError: No module named X"
  Solution: pip install --break-system-packages phonenumbers

  Problem: "Invalid phone number"
  Solution: Include country code: +2348012345678 (not 08012345678)

  Problem: "CSV not found"
  Solution: Put CSV in same directory, or use full path

  Problem: "API timeout"
  Solution: Network issue - local validation still works

  Problem: "Twilio not configured"
  Solution: Set TWILIO_ACCOUNT_SID and TWILIO_AUTH_TOKEN env vars
